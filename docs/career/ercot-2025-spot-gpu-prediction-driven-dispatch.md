# ERCOT 2025 Spot GPU 预测驱动调度

## 项目定位

本项目面向“业务预测与决策智能”岗位，构建**真实 Spot GPU 作业重放下的预测驱动数据中心日前调度**。它以购电价、光伏出力和风电出力的日前预测为上游，以 Spot 作业执行、购电和储能调度为下游，并以真实能源信号结算预测导致的成本差异。

项目是跨域数据驱动的反事实重放实验：真实生产级 GPU 作业轨迹被重放到 ERCOT 2025 年能源信号上。它不是阿里巴巴集群在 Houston 或 ERCOT 的历史运行记录，也不将系统级风光解释为 Houston 本地发电数据。

## 数据边界

| 数据 | 作用 | 已核验边界 |
| --- | --- | --- |
| ERCOT 2025 年 `LZ_HOUSTON` DAM 价格 | 日前购电成本信号与预测目标 | 8,760 个小时，价格字段无缺失 |
| EIA ERCO 2025 年 `NG: SUN` 与 `NG: WND` | 系统级风电、光伏信号与预测目标 | 时间索引全年逐小时连续；两个目标各有 48 个原始缺失时点 |
| Alibaba Spot GPU 作业表 | 可延迟作业的重放到达、资源请求与持续时间 | 51,154 个 `Spot` 作业；提交时间为相对秒数，无公开绝对日期、地点或时区 |
| Alibaba GPU 节点表 | 作业资源请求的节点容量语境 | 4,278 个节点；不提供实测功耗 |

原始文件及其来源、哈希和字段说明保留在 `data/energy/` 与 `data/workload/`。求职线只读取经论文线生成并审计的公共年度能源表；论文线的固定窗口输入快照不得充当求职线训练、验证或测试划分。

## 第一阶段范围

### 上游预测

每个日前截止点预测下一调度窗口的：

1. `LZ_HOUSTON` DAM 价格；
2. ERCOT 系统级光伏信号；
3. ERCOT 系统级风电信号。

训练、验证和测试必须严格按时间顺序切分。每次预测只使用截止点之前可获得的数据，且每个正式窗口必须通过时间连续性和缺失值检查。第一阶段不对原始缺失时点进行隐式填补；只使用记录在输入清单中的合格窗口。

### 作业重放与日前调度

Spot 作业使用提交时间、资源请求和持续时间构造相对时间重放负荷。重放锚点、时间缩放、作业可延迟规则，以及 GPU 资源到调度负荷的转换必须单独配置、可复现并在报告中披露。由于节点表没有实测功耗，第一阶段不得将转换后的负荷称为实测 MW。

预测值仅作为日前调度输入。调度层决定 Spot 作业的执行时段、购电和储能动作；实际价格、风电和光伏信号只在事后结算时使用。

## 实验对照与指标

每个合格测试窗口必须同时输出：

1. **完全信息调度**：以测试窗口真实价格与真实风光信号为事后参考；
2. **基线预测调度**：以已记录的朴素时间序列预测作为输入；
3. **模型预测调度**：以通过验证集选择的特征模型预测作为输入。

预测层报告价格、光伏和风电各自的 MAE 与 RMSE。决策层以真实值结算总成本、购电成本、可再生能源弃电量、储能吞吐量和 Spot 作业服务指标。模型预测调度相对完全信息调度的实际结算成本差额定义为决策遗憾。

## 明确排除项

- 不把当前固定分时电价称为市场价格预测；
- 不使用随机打乱的时间序列划分；
- 不把未来真实值作为预测值输入；
- 不将优化目标值当作实际结算成本；
- 不在第一阶段加入 GPU 工作负载预测、碳优化、概率预测或鲁棒优化。

GPU 工作负载预测和碳优化仅在完成 GPU 资源到功耗的可审计转换、且选择不含所需目标缺失值的连续窗口后，才可单独评估是否扩展。
