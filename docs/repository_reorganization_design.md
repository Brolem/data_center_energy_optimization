# 数据中心能源优化仓库重组设计

## 1. 目标

重组只调整仓库内部结构、职责和命名，不修改 Houston 2020 主实验的数学模型、参数、输入数据字节、四组算例或数值结果。项目正式名称为 `data_center_energy_optimization`，Python 包名为 `dc_energy_opt`，正式运行入口为 `run_day_ahead_experiment.py`。本阶段不移动工作区根目录，也不修改远程仓库名称。

## 2. 职责边界

- `dc_energy_opt/config.py`：参数和计算属性；
- `dc_energy_opt/data/`：工作负载与能源数据读取、校验和聚合；
- `dc_energy_opt/optimization/`：窗口模型、跨日状态和滚动日前调度；
- `dc_energy_opt/experiments/`：主实验编排、输入快照和事务化发布；
- `dc_energy_opt/reporting/`：指标汇总、版本记录和绘图；
- `archive/legacy_phoenix/`：不由正式包导出的历史场景、数据与独立测试。

正式 CLI 只解析参数、调用实验函数并打印摘要；它不构建模型、绘图或实现文件回滚。数据模块不写实验输出，优化模块不复制输入文件，指标模块不绘图。

## 3. 数据与输出

正式数据固定在 `data/workload/` 和 `data/energy/`。每个目录提供字段、时间、来源和哈希说明。实验先把输入复制到同级临时运行目录，再从不可变快照加载并求解，确保已发布输入与实际模型输入一致。

输出按 `inputs/`、`results/`、`figures/` 和 `models/` 分层。LP 按算例、滚动窗口和两级目标保存。完整临时目录验证成功后整体发布；发布失败时恢复旧结果，并避免沿符号链接或目录联接删除外部目标。

## 4. 测试与文档

正式测试分为 `tests/unit/` 和 `tests/integration/`，默认发现命令不运行归档测试。单元测试对应配置、数据、窗口模型、指标与绘图；集成测试对应滚动调度、完整实验、事务发布和 CLI。

`docs/` 保持单层结构，分别说明数学模型、主实验、重组设计、实施清单和最终报告。根目录 README 只提供简介、安装、快速运行、输出和文档导航。

## 5. 验收原则

- 两个正式数据文件的 SHA256 保持不变；
- 正式输出仍为四组算例、2,700 行小时结果、112 行日指标、232 个 LP 和 5 张图；
- 新结构结果与冻结基线逐列等价，计时列只验证有限且非负；
- 正式与归档测试、Python 编译、依赖检查和差异格式检查全部通过；
- 不推送、不合并、不改工作区根目录或远程仓库名称。
