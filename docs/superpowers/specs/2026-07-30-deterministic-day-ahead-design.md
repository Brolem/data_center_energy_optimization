# Houston 2020 跨日确定性日前优化设计

## 目标与边界

模型在 Google 2019 的 28 天聚合 CPU 轨迹上执行滚动 24+3 小时确定性日前调度。每个窗口固化前 24 小时，任务与 SOC 跨日连续；本阶段使用准确预测，不包含日内修正、预测误差、实时电价、任务削减、算力缺口或售电。

正式实验只比较 `renewables_only`、`renewables_shift`、`renewables_storage` 和 `joint`，成本基准为 `renewables_only`。6.6 MW 并网容量只作为共同物理约束。

## 输入

能源场景严格包含 699 个 Houston 固定 UTC−06 小时：24 小时预热、672 小时分析期和 3 小时结算尾段。风光来自固定版本的 `dos-group/vessim-opt`：NSRDB + PVWatts v8 生成 3 MWdc 光伏的交流出力；WIND Toolkit 80 m 风速 + GE 1.5sle 功率曲线生成单机容量因子并缩放到 6.6 MW。

分段电价按小时重复：00:00–07:59 为 0.1804 CNY/kWh；09:00–12:59、18:00–22:59 为 0.7174 CNY/kWh；其余时段为 0.4489 CNY/kWh。它是外生论文价格信号，不解释为 Houston 当地电价。

## 设备尺度

- 12,500 台服务器，0.55 kW/台最大功率，空闲比例 0.60，PUE 1.10；
- 光伏 3.0 MWdc，DC/AC 比 1.15，交流逆变器约 2.609 MW；
- 风电 6.6 MW；
- 电网 6.6 MW；
- 储能 2 MWh，充放电功率各 0.5 MW，效率 0.95/0.90；
- SOC 0.10–0.90，实验初末均为 0.50。

## 模型

每小时满足：

\[
P_t^{grid}+P_t^{solar,use}+P_t^{wind,use}+P_t^{dis}
=P_t^{dc}+P_t^{ch}.
\]

风光分别满足“利用 + 弃电 = 可用”；电网功率非负且不超过 6.6 MW。储能状态为：

\[
E_{t+1}=E_t+0.95P_t^{ch}-P_t^{dis}/0.90,
\quad 0.2\le E_t\le1.8.
\]

充放电二进制状态互斥，不设置活动小时数上限。柔性任务占到达负荷的 30%，必须在到达后 3 小时内完成；非柔性任务到达即执行。

一级目标为购电、光伏运维、风电运维、储能吞吐运维和放电循环退化五项成本之和。一级成本在 0.01 CNY 内固定后，二级最小化任务总延迟。弃电只报告，不惩罚。

## 跨日机制

预热窗口使用第 28 天工作负荷生成 5 月 1 日遗留任务，预热成本不计入实验。储能算例先执行覆盖 675 小时的 SOC 协调模型，固定初末电量 1.0 MWh，并提取每日第 24 小时末边界。滚动窗口使用这些边界，传递第 24 小时末电量和 21–23 时未完成任务。第 28 天窗口在 3 小时结算尾段完成全部遗留任务，尾段不产生新任务，结束电量恢复到 1.0 MWh。

## 验收

- Houston 场景 699 小时连续且容量边界正确；
- 四组算例各输出 672 小时分析期和 3 小时结算尾段；
- 功率平衡、风光守恒、CPU 守恒误差在数值容差内；
- 并网功率不超过 6.6 MW；
- SOC 位于 0.10–0.90，初末电量均为 1.0 MWh；
- 充放电均不超过 0.5 MW且不同时发生；
- 任务最大延迟不超过 3 小时；
- 五项成本可从小时结果独立重算；
- 不可行输入明确报错，不扩大容量或削减任务。
