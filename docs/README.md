# 文档索引

当前文档只保留四个入口：

- [项目架构](architecture.md)：两条主线、共享底座、依赖方向和维护规则；
- [论文线](paper/README.md)：模型、实验与正式结果；
- [求职线](career/README.md)：当前边界与后续展示方向；
- [开发状态](development/README.md)：按论文线、求职线和共享改动隔离的进行中范围与验收记录。

`archive/` 保存历史设计和实施记录，不作为当前做法的依据。新功能在对应主线的 `development/` 子目录中记录进行中范围与验收；完成后只把长期有效内容写回架构或对应主题文档，历史由 Git 保存。
